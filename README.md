# REST Engine --- Portfolio-Grade Production Microservice

## Overview
REST Engine ek enterprise-ready, portfolio-grade FastAPI microservice hai jo high-performance asynchronous database persistence, advanced filtering/pagination, rate-limiting, structured telemetry, aur automated CI/CD pipeline ke sath build kiya gaya hai.

## Tech Stack
- **API Framework:** FastAPI (Async)
- **Database:** SQLAlchemy 2.0 with aiosqlite (Async)
- **Validation:** Pydantic v2
- **Testing:** Pytest (Async integration coverage)
- **CI/CD:** GitHub Actions (Automated testing & Docker build)
- **Telemetry:** Loguru (Structured JSON logging)
- **Security:** Rate limiting (SlowAPI), CORS, Trusted Host middleware

## Features
- **Async Persistence:** SQLAlchemy 2.0 async sessions for non-blocking DB operations.
- **Advanced Filtering/Sorting:** Support for search (title/desc), category, price ranges, and sorting (price/created_at).
- **Pagination:** Standardized metadata envelope (`total`, `page`, `size`, `items`).
- **Observability:** Structured JSON logs with unique `X-Request-ID` correlation.
- **Security:** Built-in rate limiting, CORS protection, and security HTTP headers.

## API Documentation
The API documentation is automatically generated by FastAPI. After starting the server, access it at:
- Swagger UI: `http://localhost:8000/docs`
- ReDoc: `http://localhost:8000/redoc`

## Local Setup
1. Clone the repo.
2. Create virtual environment: `python -m venv .venv`
3. Activate: `source .venv/bin/activate` (Linux/Mac) or `.venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run tests: `pytest`
6. Run server: `uvicorn app.main:app --reload`

## Docker Deployment
```bash
docker build -t rest-api-engine .
docker run -p 8000:8000 rest-api-engine
```
